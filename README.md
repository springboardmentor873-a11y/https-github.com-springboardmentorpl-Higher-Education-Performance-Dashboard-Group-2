# Higher Education Performance Dashboard 📊

## 📌 Overview

This project is an interactive **Tableau dashboard** for analyzing higher education performance using university ranking and performance data. It provides insights into **university rankings, research performance, student diversity, and country-wise comparisons**.

## ✨ Features

- University ranking analysis
- Research performance analysis
- Student and faculty analysis
- Country-wise comparison
- Interactive filters and visualizations
- KPI-based performance analysis

## 📊 Dashboards

### 🎓 University Overview
Analyze university rankings, reputation, and overall performance.

### 🔬 Research Analytics
Explore research productivity, publications, citations, and research impact.

### 👨‍🎓 Student Analytics
Analyze student diversity, international students, enrollment, and faculty-to-student ratio.

### 🌍 Country Comparison
Compare higher education performance across different countries and regions.

## 🛠️ Tech Stack

- **Python**
- **Pandas & NumPy**
- **Tableau**
- **QS World University Rankings**
- **Times Higher Education World University Rankings**

## 📈 Key KPIs

- Global Ranking Score
- Research Impact Score
- Faculty-to-Student Ratio
- International Student Percentage
- Academic Reputation Score
- Research Productivity Index
