🎓 EduVision – Higher Education Performance Dashboard
📌 About the Project

EduVision is a higher education analytics project developed to analyze and visualize university performance using ranking and academic performance data. The project combines data from university ranking sources and transforms it into meaningful Key Performance Indicators (KPIs) and interactive Tableau dashboards.

The main purpose of EduVision is to help users easily understand which universities perform well, how research performance differs, how students are distributed, and how countries compare in higher-education performance.

🎯 Project Objectives

🏆 Analyze University Rankings
Identify and compare universities based on their overall ranking performance and academic indicators.

🔬 Evaluate Research Performance
Analyze research-related indicators and identify institutions with stronger research impact and productivity.

👨‍🎓 Analyze Student Performance
Study international student representation, student diversity, and faculty-to-student relationships.

🌍 Compare Countries
Benchmark countries based on university performance, academic reputation, research impact, and other education indicators.

📊 Create Interactive Dashboards
Develop visually attractive Tableau dashboards that allow users to explore higher-education data through filters and comparisons.

✨ Key Features

🏫 University Analysis

EduVision provides a detailed view of university performance by combining ranking scores and academic indicators. Users can compare institutions and identify top-performing universities.

🔬 Research Analytics

The Research Analytics dashboard focuses on research performance and productivity. It helps users understand differences between universities and regions in terms of research impact.

👨‍🎓 Student Analytics

The Student Analytics dashboard provides insights into international student representation, faculty-to-student ratios, and student distribution across universities and regions.

🌎 Country Comparison

The Country Comparison dashboard enables benchmarking of countries based on university rankings, academic reputation, research performance, and student-related indicators.

🎯 KPI-Based Analysis

Several education KPIs are calculated to convert raw ranking data into meaningful measures that can be easily analyzed and visualized in Tableau.

📊 Key Performance Indicators

🏆 Global Ranking Score
Represents the overall performance of a university based on ranking information.

🔬 Research Impact Score
Measures the research performance of an institution using available research-related indicators.

👩‍🏫 Faculty-to-Student Ratio
Provides an indication of faculty availability in relation to students.

🌐 International Student Percentage
Shows the representation of international students within the university population.

⭐ Academic Reputation Score
Represents the academic reputation of a university based on the available ranking indicator.

📚 Research Productivity Index
Provides an indicator for comparing research productivity between institutions.

📊 Tableau Dashboards
🎓 University Overview

The University Overview dashboard presents the overall performance of universities through ranking comparisons, academic reputation analysis, regional distribution, and institutional performance.

🔬 Research Analytics

The Research Analytics dashboard examines research productivity, research impact, top research institutions, and regional research performance.

👨‍🎓 Student Analytics

The Student Analytics dashboard focuses on international student representation, faculty-to-student ratios, student diversity, and student distribution.

🌍 Country Comparison

The Country Comparison dashboard compares countries using university ranking performance, academic indicators, research impact, and regional education performance.

🔄 Project Workflow

📥 Data Collection
University ranking datasets are collected from available higher-education ranking sources.

⬇️

🧹 Data Cleaning
Duplicate records are removed, university and country names are standardized, and data quality issues are addressed.

⬇️

⚙️ KPI Engineering
Important education performance indicators are calculated from the cleaned dataset.

⬇️

📊 Dashboard Development
The processed dataset is connected to Tableau to create interactive visualizations.

⬇️

🔗 Dashboard Integration
The four dashboards are connected using navigation, filters, and interactive dashboard features.

⬇️

✅ Testing & Validation
KPIs, rankings, filters, charts, and dashboard navigation are checked for accuracy and functionality.

🛠️ Technologies Used

🐍 Python – Data processing and KPI calculation
🐼 Pandas – Data cleaning and transformation
🔢 NumPy – Numerical calculations
📊 Tableau – Interactive dashboard development
📁 CSV / Excel – Data storage and Tableau-ready datasets
