# https-github.com-springboardmentorpl-Higher-Education-Performance-Dashboard-Group-2
## Milestone 1 – Data Collection and Preparation

As part of the Infosys Springboard Virtual Internship 7.0, Milestone 1 focuses on data collection, cleaning, and preparation for the Higher Education Performance Dashboard.

### Module 1 – University Data Collection
- Collected university ranking datasets.
- Collected university performance indicators.
- Integrated the ranking datasets into a common structure.

### Module 2 – Data Cleaning & Transformation
- Removed duplicate records.
- Standardized university names.
- Standardized country names.
- Normalized ranking metrics.
- Prepared clean datasets for further analysis and Tableau dashboard development.
