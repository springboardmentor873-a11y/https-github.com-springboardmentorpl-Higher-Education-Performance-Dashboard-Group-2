# 🎓 EduVision – Global University Analytics Dashboard

EduVision is an interactive Tableau-based education analytics project designed to analyze global university performance, research strength, student-related indicators, and country-level education performance.

The project transforms university ranking and education data into an interactive dashboard suite that helps users compare universities, research performance, student indicators, and countries.

---

## 📌 Project Overview

EduVision provides a centralized analytics platform containing four major dashboards:

1. University Overview
2. Research Analytics
3. Student Analytics
4. Country Comparison

The dashboards use interactive filters, navigation buttons, KPI cards, charts, maps, and comparison views to make the analysis simple and user-friendly.

---

## 🎯 Project Objectives

The main objectives of EduVision are:

- Analyze global university performance.
- Compare universities using ranking and academic indicators.
- Analyze research impact and productivity.
- Understand student-related indicators.
- Compare education performance between countries.
- Identify top-performing universities and countries.
- Provide an interactive and professional Tableau dashboard.
- Present meaningful insights through KPIs and visual analytics.
