# EduVision — Dataset Sources

## 1. Dataset Overview

The EduVision project uses a higher education dataset containing university-level and country-level information for educational performance analysis.

The dataset is used to analyze:

- University rankings
- Academic reputation
- Global ranking
- Overall scores
- Research impact
- Research productivity
- International students
- Faculty-to-student ratio
- Country-level educational performance

---

## 2. Dataset Fields Used

The dashboard uses metrics related to:

- University Name
- Country
- Academic Reputation
- Global Ranking
- Overall Score
- Research Impact
- Research Productivity
- International Students
- Faculty-to-Student Ratio

---

## 3. Data Processing

The dataset was processed before visualization.

The project workflow included:

1. Data collection
2. Data inspection
3. Data cleaning
4. Data validation
5. Exploratory analysis
6. KPI generation
7. Tableau visualization
8. Dashboard validation

---

## 4. Data Quality

The dataset was reviewed for:

- Missing values
- Invalid values
- Duplicate records
- Data type consistency
- Country names
- University names
- Numeric metric consistency

Data preparation was performed using Python-based scripts before visualization in Tableau.

---

## 5. Dataset Usage

The dataset is used strictly for educational analytics and dashboard development as part of the EduVision project.
