# Module 3 – Education KPI Engineering

## Project
EduVision_DV – Higher Education Performance Dashboard

## Purpose
Calculate education-focused performance KPIs from the merged university dataset.

## KPIs
- Global Ranking Score
- Research Impact Score
- Faculty-to-Student Ratio
- International Student Percentage
- Academic Reputation Score
- Research Productivity Index

## Tasks
- Load the merged QS and THE dataset.
- Calculate six education performance KPIs.
- Prepare the final dataset for Tableau visualization.

## Files
- `merged_QS_THE_2026.xlsx` – Merged QS and THE dataset
- `generate_education_kpis.py` – KPI generation script
- `university_final_dataset.xlsx` – Final KPI-ready dataset

## Next Module
The final KPI dataset is used for dashboard planning and visualization in the next modules.
