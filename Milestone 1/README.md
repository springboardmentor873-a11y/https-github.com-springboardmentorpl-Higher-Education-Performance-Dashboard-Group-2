# Milestone 1: Data Collection and Preparation

## Objective

Collect, clean, and prepare university ranking and performance datasets for the EduVision Higher Education Performance Dashboard.

## Tasks

- Collect QS World University Rankings data
- Collect Times Higher Education World University Rankings data
- Collect university performance indicators
- Merge ranking datasets into a common structure
- Remove duplicate records
- Standardize university names
- Standardize country names
- Normalize ranking metrics
- Create Tableau-ready datasets

## Deliverables

- Raw university dataset
- Cleaned university dataset
- Data collection script
- Data cleaning and transformation notebook

## Evaluation Criteria

- Dataset completeness above 95%
- Less than 2% missing values
- Consistent ranking indicators
