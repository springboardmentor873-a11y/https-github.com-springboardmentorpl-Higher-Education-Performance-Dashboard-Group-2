# Module 2 – Data Cleaning & Transformation

## Project
EduVision_DV – Higher Education Performance Dashboard

## Purpose
Clean and transform university ranking datasets into consistent, analytics-ready data.

## Tasks
- Remove duplicate records.
- Standardize university names.
- Standardize country names.
- Normalize ranking metrics.
- Create Tableau-ready datasets.

## Files
- `QS_cleaned_2026.xlsx` – Cleaned QS ranking dataset
- `THE_cleaned_2026.xlsx` – Cleaned THE ranking dataset
- `education_cleaning.ipynb` – Data cleaning and transformation notebook
