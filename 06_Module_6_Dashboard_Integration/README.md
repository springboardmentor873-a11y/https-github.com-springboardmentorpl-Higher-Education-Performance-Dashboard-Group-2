# Module 6 – Dashboard Integration

## EduVision_DV | Higher Education Performance Dashboard

### 1. Module Overview

Module 6 focuses on **integrating the complete EduVision_DV Tableau dashboard suite** into a unified and interactive dashboard solution.

This module brings together the four major dashboards:

- University Overview
- Research Analytics
- Student Analytics
- Country Comparison

The objective is to provide a connected dashboard experience with consistent navigation, filters, dashboard actions, and interactive analysis.

---

### 2. Module Objectives

The main objectives of Module 6 are:

- Develop the Student Analytics dashboard.
- Develop the Country Comparison dashboard.
- Integrate all four dashboards into a unified Tableau workbook.
- Implement global filters.
- Configure navigation controls.
- Implement dashboard actions.
- Enable interactive comparisons.
- Link the dashboards together.
- Verify that the integrated dashboard functions correctly.

---

### 3. Student Analytics Dashboard

The Student Analytics dashboard focuses on student-related university performance indicators.

The dashboard provides analysis of:

- International student performance
- Faculty-to-student ratio
- Student diversity
- Student distribution
- Enrollment comparisons
- International student comparisons

The dashboard enables users to explore student-related indicators across universities and countries.

---

### 4. Country Comparison Dashboard

The Country Comparison dashboard provides country-level education performance analysis.

The dashboard focuses on:

- Country ranking comparison
- Education performance benchmarking
- Regional education trends
- Top-performing countries
- University distribution by country
- Country-level performance comparison

This dashboard helps users compare higher-education performance across different countries.

---

### 5. Dashboard Integration

The complete EduVision_DV dashboard suite is connected through Tableau navigation and interactive controls.
6. Global Filters

Global and dashboard-level filters are used to support interactive exploration of the data.

The dashboard suite includes filters such as:

Country
University
Ranking-related criteria
Performance-related criteria

Filters allow users to dynamically change the information displayed in the dashboard visualizations.

7. Navigation Controls

Navigation controls are implemented to provide access to the different dashboard views.

The navigation structure includes:

Home
  ↓
University Overview
  ↓
Research Analytics
  ↓
Student Analytics
  ↓
Country Comparison

Users can move between the dashboard sections without leaving the Tableau workbook.

8. Dashboard Actions

Tableau dashboard actions are used to improve interactivity between dashboard components.

The integration includes:

Dashboard navigation
Filter actions
Interactive selections
Dashboard linking
Parameter-based interactions where required

These features allow users to interact with the dashboard and explore related information.

9. Final Tableau Workbook

The integrated EduVision_DV Tableau workbook is stored in:

tableau/EduVision_DV.twbx

This workbook contains the integrated dashboard suite developed for the project.
