# Module 5 – Dashboard Development

## EduVision_DV | Higher Education Performance Dashboard

### 1. Module Overview

Module 5 focuses on the **development of the University Overview and Research Analytics dashboards** using Tableau.

The cleaned and KPI-enhanced university dataset prepared in the previous modules is used to create interactive visualizations for analyzing university rankings, academic performance, research impact, and research productivity.

---

### 2. Module Objectives

The main objectives of Module 5 are:

- Develop the University Overview dashboard.
- Develop the Research Analytics dashboard.
- Create interactive Tableau visualizations.
- Analyze university ranking and academic performance.
- Analyze research impact and productivity.
- Create meaningful charts and analytical views.
- Implement dashboard filters and interactions.
- Validate ranking-related visualizations.
- Prepare the first dashboard development version.

---

### 3. University Overview Dashboard

The University Overview dashboard provides a high-level view of university performance.

The dashboard includes analytical views such as:

- Top university rankings
- Global university distribution
- Academic reputation analysis
- Overall score distribution
- Institutional comparison
- University performance analysis

The dashboard helps users understand overall university performance and compare institutions across available indicators.

---

### 4. Research Analytics Dashboard

The Research Analytics dashboard focuses on research-related university performance.

The dashboard includes analytical views such as:

- Research impact analysis
- Research impact distribution
- Research productivity analysis
- Research productivity distribution
- Research impact comparison
- Research performance by country

The dashboard helps users explore differences in research performance between universities and countries.
