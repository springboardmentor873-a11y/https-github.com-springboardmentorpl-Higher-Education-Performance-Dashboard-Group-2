# Module 1 – University Data Collection

## Project
EduVision_DV – Higher Education Performance Dashboard

## Purpose
Collect and prepare university ranking datasets for the EduVision_DV project.

## Tasks
- Prepare QS Ranking dataset.
- Prepare Times Higher Education (THE) dataset.
- Collect university performance indicators.
- Prepare source datasets for further integration and processing.

## Files
- `QS_2026.csv` – QS university ranking source dataset
- `THE_2026.xlsx` – Times Higher Education source dataset
