# Dashboard Guide

## Overview

EduVision is an interactive higher-education analytics dashboard developed using QS World University Rankings 2026 and Times Higher Education (THE) World University Rankings 2026 data.

The integrated Tableau workbook contains four dashboards:

1. Overview Dashboard
2. Research Dashboard
3. Student analysis Dashboard
4. Comparison Dashboard

---

## 1. Overview Dashboard

### Purpose

The Overview Dashboard provides a high-level view of university performance and helps users identify universities based on overall ranking and academic reputation indicators.

### Key Information

The dashboard provides access to:

- University-level performance
- Global Ranking Score
- Academic Reputation Score
- Ranking-related information
- University comparison context

### Typical Use

Use this dashboard to:

- Review overall university performance.
- Identify universities for further analysis.
- Examine academic reputation.
- Move from high-level results to detailed research or student analysis.

---

## 2. Research Dashboard

### Purpose

The Research Dashboard focuses on research performance and research-related university indicators.

### Key Information

The dashboard uses:

- Research Impact Score
- Research Productivity Index
- QS Citations per Faculty Score
- THE Research Quality
- THE Research Environment

### Typical Use

Use this dashboard to:

- Examine research performance.
- Compare research-related indicators.
- Identify differences in research impact.
- Investigate research productivity across universities.

---

## 3. Student Analysis Dashboard

### Purpose

The Student analysis Dashboard focuses on student-related university characteristics and international student representation.

### Key Information

The dashboard uses:

- International Student Percentage
- Faculty-to-Student Ratio
- Student population information
- Student-related university comparisons

### Typical Use

Use this dashboard to:

- Examine student characteristics.
- Compare international student representation.
- Review faculty and student relationships.
- Analyze student-related differences between universities.

---

## 4. Comparison Dashboard

### Purpose

The Comparison Dashboard allows users to compare universities using multiple education performance indicators.

### Key Information

The dashboard brings together:

- Global Ranking Score
- Research Impact Score
- Faculty-to-Student Ratio
- International Student Percentage
- Academic Reputation Score
- Research Productivity Index

### Typical Use

Use this dashboard to:

- Compare selected universities.
- Examine differences across multiple KPIs.
- Support university benchmarking.
- Identify strengths and differences across education metrics.

---

## Dashboard Interactions

The dashboards were designed to support interactive exploration.

Depending on the dashboard, users can interact with:

- Filters
- University selections
- Dashboard navigation
- Highlighting
- Tooltips
- Comparison views
- Reset controls

Interactive behavior was manually tested as part of Module 7.

---

## Recommended User Workflow

### Step 1 — Start with Overview

Review the overall university performance and identify universities of interest.

### Step 2 — Investigate Research

Use the Research Dashboard to examine research impact and productivity.

### Step 3 — Investigate Students

Use the Student analysis Dashboard to examine student-related indicators and international representation.

### Step 4 — Compare Universities

Use the Comparison Dashboard to compare universities across the available KPIs.

### Step 5 — Reset and Explore

Use the available reset controls when starting a new analysis.
